THE CONTROLLER

What ChoCo does

ChoCo turns a small set of physical controls into scale-aware chords. The firmware runs on a Raspberry Pi Pico and sends standard MIDI notes over USB; a connected instrument makes the sound.

Play in a scale

Keys 0–6 select the seven degrees. A changes the root note, and B cycles through nine scales.

Change the chord

Move the joystick for suspensions, sevenths, extensions and other variations. Returning to center restores the base triad.

Choose how it plays

Latch, bass, strum, single-note and smart-voicing modes change how notes are played.

See the current state

The OLED shows the selected key and scale, chord name, active modes and harmonic suggestions.
